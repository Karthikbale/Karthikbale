## 👨‍💻 About Me

I'm an **AWS DevOps Engineer** who enjoys turning manual, error-prone deployments into automated, reliable pipelines. I work across the full DevOps lifecycle — provisioning cloud infrastructure, containerizing applications, building CI/CD pipelines, and setting up monitoring so systems stay observable in production.

I like solving real infrastructure problems: scaling APIs, securing pipelines, and making deployments boring (in the best way). Currently exploring MLOps and DevSecOps practices to bring security and machine learning workflows into the same automated pipeline.

- ☁️ **Cloud Infrastructure** — designing and provisioning on AWS
- 🔄 **CI/CD Pipelines** — Jenkins, GitHub Actions, automated build & release
- 🐳 **Containerization** — Docker images, multi-stage builds
- ☸️ **Orchestration** — Kubernetes deployments and scaling
- 🏗️ **Infrastructure as Code** — Terraform for repeatable, version-controlled infra
- 🔐 **DevSecOps** — SonarQube, Trivy, security scanning in the pipeline
- 📊 **Monitoring & Observability** — Prometheus & Grafana dashboards
- 🤖 **MLOps** — deploying and serving ML models via FastAPI
